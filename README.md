# Site Pessoal - Hailton Vecchia

Este é um site pessoal/portfólio para Hailton Vecchia, desenvolvido seguindo o plano detalhado no arquivo `plano.md`.

## Estrutura do Projeto

- `index.html` - Estrutura principal do site
- `style.css` - Estilos e design do site
- `script.js` - Funcionalidades interativas
- `favicon.svg` - Ícone do site
- `plano.md` - Plano de desenvolvimento do site

## Características Implementadas

- Design responsivo para dispositivos móveis, tablets e desktops
- Modo claro/escuro com persistência via localStorage
- Animações suaves e efeitos visuais
- Navegação suave entre seções
- Formulário de contato com validação
- Modal para exibição de certificados
- Timeline para experiência profissional
- Elementos futuristas conforme especificado no plano

## Como Visualizar o Site

Para visualizar o site, basta abrir o arquivo `index.html` em qualquer navegador moderno.

```
duplo clique no arquivo index.html
```

Ou, se preferir usar um servidor local:

1. Instale o Node.js
2. Instale o pacote `http-server` globalmente: `npm install -g http-server`
3. Na pasta do projeto, execute: `http-server`
4. Acesse `http://localhost:8080` no seu navegador

## Personalização

Para personalizar o site:

1. Substitua as imagens placeholder por imagens reais
2. Atualize as informações de contato e links de redes sociais
3. Modifique o conteúdo das seções conforme necessário
4. Ajuste a paleta de cores no arquivo CSS se desejar
